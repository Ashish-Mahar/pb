# 🎵 Piyush Bhatt — Portfolio Website

Official portfolio website for **Piyush Bhatt**, a young Uttarakhandi singer from **Pithoragarh, Uttarakhand**.

A clean, responsive single-page portfolio showcasing his music, reels, gallery, and contact information for bookings and collaborations.

## ✨ Features

- 🎨 **Modern single-page design** with warm Himalayan-inspired colors
- 📱 **Fully responsive** — mobile, tablet, and desktop
- 🎬 **Dynamic Instagram Reels** — loaded from a JSON file (easy to update)
- 📸 **Photo gallery** with hover effects
- 📩 **Working contact form** via Formspree
- 💬 **WhatsApp direct booking** button
- 🔗 **Social links** (Instagram, YouTube, Spotify, Facebook)
- ⚡ **Fast loading** — no frameworks, pure HTML/CSS/JS
- 🔍 **SEO ready** — meta tags, Open Graph, Twitter Cards
- ♿ **Accessible** — keyboard navigation, reduced-motion support
- 🍔 **Mobile hamburger menu**

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Markup** | HTML5 |
| **Styling** | CSS3 (Flexbox + Grid) |
| **Logic** | Vanilla JavaScript (ES6+) |
| **Data** | JSON (for reels) |
| **Forms** | Formspree (no backend) |
| **Fonts** | Google Fonts (Poppins + Inter) |
| **Hosting** | Netlify / Vercel / GitHub Pages |

> No frameworks. No build tools. No dependencies. Just clean code.
